初回セットアップ (1回だけ)

Cloudflare API はブラウザから直接叩けない仕様(CORS 非対応)なので、橋渡し用の Worker を 1 個だけ立てます。
この作業は最初の1回だけ。以降このページから何個でも別の Worker をデプロイできるようになります。

1パスワードを決める

第三者にプロキシを勝手に使われないようにする合言葉。下のコードに自動で埋め込まれます。

2コードをコピーして Cloudflare に貼る

  1. dash.cloudflare.com → Workers & Pages → Create
  2. "Hello World" テンプレで Deploy
  3. Edit code → 全消し → 下のコードを貼り付け → Save and deploy

3デプロイした Worker の URL を貼ってテスト

Cloudflare の画面上部に出る xxxxx.<your-name>.workers.dev を貼り付けてください。
