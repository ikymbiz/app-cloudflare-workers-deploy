使い方 / How it works
  1. My Profile → API Tokens から Edit Cloudflare Workers テンプレートでトークンを作成。
  2. Workers ダッシュボード右側の Account ID をコピー。
  3. Worker 名(英数字とハイフン)を決めてコードを書く。
  4. Deploy を押すと Cloudflare API に直接 PUT されます。
  5. 成功後は https://<name>.<subdomain>.workers.dev でアクセス可能(workers.dev サブドメインを事前に有効化しておいてください)。

※トークンはブラウザのみで保持されます(localStorage)。共有 PC では「クリア」を押してください。
