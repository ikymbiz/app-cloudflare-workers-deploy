初回セットアップ (1回だけ)

Cloudflare API はブラウザから直接叩けないため、橋渡し用 Worker を 1 個だけ 立てます。
最初の1回だけの作業で、以降このページから何個でも別の Worker をデプロイ・設定できます。

1PROXY_SECRET の値

これは Cloudflare の Worker に シークレット として登録する値です(コードには含まれません)。

後で Worker の Settings → Variables and Secrets → Secret 変数として登録します

2プロキシコード (汎用)

SECRET 値は埋め込まれません。コードはそのまま貼り付けるだけ。

3Cloudflare 側の作業

  1. dash.cloudflare.com → Workers & Pages → Create → "Hello World" → Deploy
  2. Edit code → 全消し → 上のコードを貼り付け → Save and deploy
  3. Worker のトップに戻り → Settings タブ → Variables and Secrets → Add variable
      Type: Secret / Variable name: PROXY_SECRET / Value: 上のPROXY_SECRET 値 → Deploy

4URL を貼ってテスト
